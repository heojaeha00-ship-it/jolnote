선사 면접 연습실

해양대생은 선사 면접(인성, 승선 생활, 해기 직무, 영어)을 실전처럼 연습할 상대가 없고, 일반 취업 면접 연습 도구는 승선 생활, 해기 직무, 선종별 질문을 다루지 않습니다. 여기서는 선사 면접관 세 명이 돌아가며 묻고 허점을 파고듭니다. 끝나면 말한 내용과 화면 속 모습(시선·자세·표정·목소리)까지 피드백합니다.

API 키·자소서 입력 없이 실사 면접실 · 남2여1 음성 · 자소서 맞춤 질문 · 리포트까지 바로 체험합니다.

AI 면접관 (무료 · 추천)

Google AI Studio(aistudio.google.com)에서 카드 등록 없이 무료 Gemini 키를 발급받아 넣으면, 면접관이 내 답변을 읽고 즉석에서 꼬리 질문을 만들고 답변마다 허점과 개선 답변 예시를 줍니다. 키가 없으면 기본 질문 은행으로 진행하고, 끝난 뒤 무료 Claude·ChatGPT로 내용 피드백을 받을 수 있습니다.

자연스러운 면접관 목소리 (ElevenLabs 무료 · 선택)

elevenlabs.io 무료 계정의 API 키를 넣으면 실제 사람 같은 목소리로 질문합니다(월 1만 크레딧, 한 번 만든 문장은 다시 쓰여 크레딧을 아낍니다). 없거나 한도를 넘으면 브라우저 음성으로 자동 전환됩니다.

면접관별 목소리 ID 바꾸기

ElevenLabs Voice Library에서 마음에 드는 목소리의 ID를 붙여 넣으세요. 비워 두면 기본 목소리를 씁니다 — 남자1 Arnold(VR6AewLTigWG4xSOukaG)·남자2 Liam(TX3LPaxmHKxFdv7VOQHJ)·여자1 Charlotte(XB0fDUnXU5powFXDhCwa). 보이스 세팅(안정도·유사도·스타일)은 면접관별로 다르게 들어갑니다.
