# 3항사 당직일지

M/V 한바다호 3항사로 이틀을 사는 3D 선상 시뮬레이션 (Three.js, 단일 HTML).

- 데이워치 08–12 / 나이트워치 20–24: 인수인계, 항해일지, 레이더·오토파일럿, COLREG 피항, 야간 등화 식별
- 앵커링: 묘박지 접근 → 샤클 판단 → 렛고 → 브로우트업 → 흑구 게양
- 접안: 선미 스테이션 히빙라인·윈치 텐션, 스냅백 존 안전
- 회식: 건배사, 음주량 → 혈중알코올 0.03% 넘으면 당직 불가
- 선원 12명이 일과표대로 당직·작업·식사·휴식하며 층을 오가고, 협업 퀘스트(해치 점검, 식재료 운반, 해도 소개정, 실습생 교육)와 비상 소집 훈련이 있음

`index.html`을 브라우저로 열면 바로 실행. 조작: WASD 이동, 마우스 시점, E 상호작용, Tab 일정표, T 시간 가속, B 쌍안경 (모바일은 화면 조이스틱).
