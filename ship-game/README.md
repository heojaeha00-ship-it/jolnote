# 3항사 당직일지

M/V 세계로호 3항사로 이틀을 사는 3D 선상 시뮬레이션 (Three.js, 단일 HTML). 배를 전혀 몰라도 프롤로그·💡팁·추천 조치 버튼으로 플레이 가능.

- 목표: 이틀 항해를 마치고 선장 신뢰도로 S~D 평가 (S = 2항사 진급 추천)
- 데이워치 08–12 / 나이트워치 20–24: 인수인계, 항해일지, BNWAS, 오토파일럿·수동 조타, 레이더·ECDIS, COLREG 피항, 야간 등화 식별
- 비상: 맨 오버보드(윌리엄슨 턴), 기관실 화재, 블랙아웃 · 랜덤 이벤트: 고래, 돌고래, 안개, VHF 교신, 표류물, 드럼통, 커피 심부름
- 앵커링 · 접안(선미 계류) · 회식(혈중알코올 0.03%) · 비상 소집 훈련
- 선원 12명이 일과표대로 당직·작업·뷔페식 식사·휴식, 협업 퀘스트(소화·구명 설비 점검 탐험, 해치 점검, 식재료 운반, 해도 소개정)

`index.html`을 브라우저로 열면 실행. WASD 이동, 마우스 시점, E 상호작용, Tab 일정표·용어 사전, R 추천 조치 (모바일은 화면 버튼).
